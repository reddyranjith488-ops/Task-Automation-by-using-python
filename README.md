# 🤖 Task Automation with Python - CodeAlpha Internship

A simple Python automation script developed as part of the CodeAlpha Python Programming Internship.

---

## 📌 Project Description

This project automatically moves all `.jpg` image files from one folder to another using Python.

It demonstrates automation concepts and file handling operations in Python.

---

## 🚀 Features

- Automatically detects `.jpg` files
- Moves files between folders
- Simple and beginner-friendly automation script
- Uses built-in Python modules

---

## 🛠️ Technologies Used

- Python
- VS Code

## 📚 Concepts Used
